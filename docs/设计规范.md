# 设计规范 ·「纸与墨」设计系统（tokens v4）

> **定位**：界面改动的**唯一事实源**。改颜色/字体/图标/动效/组件样式前必读；只改业务代码不用读。
> **范围**：视觉与交互的一致性规则（排版 / 色彩 / 动效 / 图标 / 层级 / 门禁）。布局之外的业务逻辑见 `docs/项目规范.md`。
> **来源**：第六期「单词即海报」落地的设计系统（2026-09），v4 于 2026-10-28 做第二轮现代化（层级阶梯 / 结构去重 / 可访问性）。
> **核心命题**：**单词即海报** —— 每一屏只有一个视觉主角（当前词），其余控件、提示、次要操作一律退到配角位。

## 1. 设计语言

### 1.1 排版

| 角色 | 字体栈（`tokens.css` 的 `--font-*`） | 说明 |
| --- | --- | --- |
| 词面 hero | `Fraunces → Georgia → Palatino → serif` | 题干单词、词卡词头、章节名、例句英文；`font-optical-sizing: auto` |
| 中文正文 | 系统 CJK 栈（西文优先 Atkinson Hyperlegible） | **禁止加载中文 webfont**（MB 级字库会毁掉离线与首屏） |
| 音标 / 数字 / 计时 | `IBM Plex Mono → ui-monospace` | 一律 `tabular-nums`，数字不跳宽 |

字号 8 级（`--fs-xs … --fs-hero`），正文行高 `--lh-body: 1.7`。

**字体自托管升级位**：本仓库构建环境无外网，woff2 未入库，当前走 Georgia / Plex 回退栈。有网时按 §1.1 注释下载 latin 子集（约 30KB/个）放入 `public/fonts/`，在 `tokens.css` 顶部追加 `@font-face`（`font-display: swap`）、两个 HTML 各加一行 `<link rel="preload" as="font" …>` 即生效，**无需改代码**。注意：门禁禁止外部字体源与 `@import`。

### 1.2 色彩（纸与墨）

- 浅色 = 暖纸 `#f7f5f1`（+ SVG `feTurbulence` 噪点纸纹，零图片请求）；深色 = 墨舱 `#101218`。
- **三层 token**：primitive → semantic（组件只许引用这层）→ component。
  `scripts/check.mjs` §8 设计 lint 强制：**组件 CSS 裸 hex = 门禁失败**。
- 六色 `data-accent` 调色盘机制保留（色值已完成 AA 调校，全部继承）。
- 事件色 =「批改」隐喻：`--ok` 墨绿 `#076a4a`、`--bad` 朱砂 `#b3261e`、`--warn` 琥珀 `#8b4a0a`。
  **三者都必须在 `--surface`、`--surface-2` 以及各自的 `*-soft` 淡底上 ≥4.5**——小字标签（核心/高频/识记、易错计数）就长在淡底上，只测白底会漏（2026-10-28 axe 实测：原 `#c9372c` 在次面板只有 4.46、`#a75a09` 只有 4.42）。
- 双主题（浅/深）正文与关键色对比度 **≥ 4.5**，新增色值必须过对比度门禁。
- **遮罩色语义化**（v4）：`--scrim` 浅色暖墨 `rgba(28,22,14,.42)` / 深色浓墨 `rgba(4,6,12,.66)`；
  弹层遮罩不再写死 rgba（浅色下与暖纸同调，深色下才压得住前后景）。
- **高对比度偏好**（v4）：`prefers-contrast: more` 只加深 `--line` / `--line-2`（结构线可见性），
  不动色相与文字色（文字对比度已双主题达标）。

### 1.3 动效

- 时长：`--dur-fast 150ms` / `--dur 240ms` / `--dur-slow 360ms`，进入用 `--spring`。
- **进场 ease-out / 退场 ease-in**（v4 新增 `--ease-in`）：同一条时间线上"消失"永远比"出现"快一档，
  例：toast 进场 `toast-in`（ease-out）+ 退场 `toast-out`（ease-in）。
- 错落入场（v4）：讲义词卡前 40 张按 `--enter-i`（0-7，JS 内联）逐个延迟 35ms，封顶 245ms；
  默认值定义在 `.grid`，`check` §5 要求 `var(--x)` 必须有 CSS 定义。
- **主题切换**（2026-10-28）：设置里主动切换走 View Transitions 根快照 **240ms 交叉淡入**（`setThemeAnimated`），
  只对可见视口快照一次，比逐层给 surface 挂 color transition 便宜；首屏主题脚本与跨标签页跟随不走这条路径，
  不会与防闪白打架；不支持或 reduced-motion 时自动退回瞬时切换。
- **全部受 `prefers-reduced-motion` 约束**（tokens 的全局降级会同时清掉 delay，避免元素一直不可见）。
- 高光只给判分时刻：答对槽格墨绿涟漪（`ink-ripple`）、换词槽位落墨入场（`ink-in`）、辨析卡以「批注纸」形态弹入。
- 当前输入位常驻呼吸光环（`caret-breathe`，1.6s，单元素单动画，随 reduced-motion 停）。
- 禁止视差 / 粒子装饰类动效。讲义词卡 → 详情走 **View Transitions 词头共享元素**。

### 1.4 图标

- emoji → **内联 SVG sprite**（`#i-*` 符号，`currentColor` 着色）。结构性控件（导航 / 同步态 / 朗读 / 报错 / 标记 / 分页）全部图标化。
- **sprite 唯一定义在 `public/ui.js`**（v4）：`SPRITE_HTML` + `ensureSprite()`，模块求值时同步注入，
  四页 HTML 不再各自内联同一份 28 符号块（原先 112 行重复、改一处要改四页）。
  Node 环境（`check.mjs` 的 import 检查）下注入自动跳过；幂等（已有 `#sprite` 则跳过）。
- ★ ☆ ✓ ✗ ✕ 保留为**文本字形**（无 VS16、可着色，lint 白名单放行）。
- 章节列表不用 emoji，改**编号瓷片**（`.ch-tile`，衬线数字）。

### 1.5 关键界面约定

- **刷词页**：词面 hero（`--fs-hero`）/ 墨格方格纸字母槽 / 答题卡（mono keycap + 抬升阴影）/ **底部拇指坞**（`提交` 主 CTA 居中，`生词·不会·上一个·重置本题` 侧翼，其余收进「⋯」快捷菜单）/ 顶栏每日目标 SVG 进度环。
- **操作坞控件 id 不变、事件绑定零改动**——改布局不改接线。
- **讲义页**：词卡衬线词头 + `content-visibility:auto` / ⌘K、Ctrl+K、`/` 命令面板 / 搜索框 SVG 放大镜。
- **存储**：配图 / 批注 / 画笔 dataURL 走 **IndexedDB**（`public/idb.js`），localStorage 只留备注与元数据。
- **键盘可达（v4）**：四页 `<body>` 首个元素是 `.skip-link`（`跳到主内容` → 各自 `<main id="main" tabindex="-1">`，
  报告页指向 `#reportRoot`）；默认移出视口，聚焦时滑出。`html` 带 `scroll-padding-top` 避免落点被吸顶栏遮住。
- **弹层（v4）**：`openLayer` 打开时锁 `body` 滚动（嵌套浮层用计数防提前解锁），关闭还原焦点与滚动。

### 1.6 层级（z-index）

全站只允许使用 `tokens.css` 的 `--z-*` 阶梯，**禁止在组件里写魔法数字**（原先 15/20/30/60/70/80/90 散落四页，
加一层就要全局搜数字）：

| token | 值 | 使用者 |
| --- | --- | --- |
| `--z-dock` | 15 | 刷词页底部操作坞（sticky） |
| `--z-menu` | 20 | 「⋯」快捷菜单 |
| `--z-sticky` | 30 | 吸顶栏 |
| `--z-overlay` | 60 | 弹层遮罩 `.scrim` |
| `--z-fab` | 70 | 讲义页画笔悬浮按钮 |
| `--z-canvas` | 80 | 整页画笔 canvas |
| `--z-toast` | 90 | toast 与画笔工具条 |

## 2. 门禁（设计相关）

| 机制 | 位置 | 内容 |
| --- | --- | --- |
| 设计 lint | `scripts/check.mjs` §8（4 项） | ① 组件 CSS 禁裸 hex ② 四页 HTML + 公共 JS/CSS 禁 emoji ③ 全 CSS 禁 `outline:none` ④ 禁外部字体源 / `@import` |
| 对比度门禁 | `scripts/check.mjs` §6 | 六盘 ink ≥4.5 双主题；正文 `text-3` / `ok` / `bad` / `warn` 在面板与次面板均 ≥4.5 |
| 毛玻璃纪律 | `scripts/check.mjs` §8e | 全屏遮罩禁 `backdrop-filter`；reduced-motion 与 `@supports` 必须有不透明回落 |
| CSS 变量完整性 | `scripts/check.mjs` §5 | 所有 `var(--x)` 必须有定义（含 JS 内联写入的 `--enter-i`） |
| 视觉回归 | `npm run ui:baseline` | Playwright 5 场景截图 → `shots/baseline/`（入库）/ `shots/current/`（忽略），配 pixelmatch 类工具比对 |
| 无障碍 | `npm run a11y` | axe-core 扫**四页 × 明暗双主题**（8 次扫描），critical/serious > 0 → exit 1（缺本地包时 exit 2，不阻塞；注入走 `page.evaluate`，绕过 CSP `script-src 'self'`） |

**人工清单（v4 新增，改界面时过一遍）**：① Tab 第一下能唤出「跳到主内容」；② 弹层打开时背景不跟随滚动；
③ 触屏点按无 300ms 迟滞（`touch-action: manipulation`）；④ 系统「减少动态效果」下无残留延迟/不可见元素；
⑤ 系统「高对比度」下边框与分隔线仍可辨。

改视觉后的收口顺序：`npm run check` → `npm test` →（改了界面）`npm run smoke` → `npm run ui:baseline` → 部署后 `npm run verify:live`。

## 3. 明确不做（及理由）

- **不引框架重写**：低组件数、高状态密度的工具型页面，框架 ROI 为负。
- **不上中文 webfont**、**不做视差/粒子装饰**。
- **不做双皮肤并行**（`@layer classic/next` 在层叠上比 git 按期回滚更脆弱）→ 出问题按期 `git revert`。
- 设计改动**不碰存储协议与同步语义**（LWW / 队列是可靠性资产）。
