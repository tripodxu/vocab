## 1. 设计语言

### 1.1 排版

| 角色 | 字体栈（`tokens.css` 的 `--font-*`） | 说明 |
| --- | --- | --- |
| 词面 hero | `Fraunces → Georgia → Palatino → serif` | 题干单词、词卡词头、章节名、例句英文；`font-optical-sizing: auto` |
| 中文正文 | 系统 CJK 栈（西文优先 Atkinson Hyperlegible） | **禁止加载中文 webfont**（MB 级字库会毁掉离线与首屏） |
| 音标 / 数字 / 计时 | `IBM Plex Mono → ui-monospace` | 一律 `tabular-nums`，数字不跳宽 |

字号 8 级（`--fs-xs … --fs-hero`），正文行高 `--lh-body: 1.7`。

**字体自托管升级位**：本仓库构建环境无外网，woff2 未入库，当前走 Georgia / Plex 回退栈。有网时按 §1.1 注释下载 latin 子集（约 30KB/个）放入 `public/fonts/`，在 `tokens.css` 顶部追加 `@font-face`（`font-display: swap`）、两个 HTML 各加一行 `<link rel="preload" as="font" …>` 即生效，**无需改代码**。注意：门禁禁止外部字体源与 `@import`。

### 1.2 色彩（纸与墨）

- 浅色 = 暖纸 `#f6f2ea`（+ SVG `feTurbulence` 噪点纸纹，零图片请求）；深色 = 墨舱 `#12141c`。
- **三层 token**：primitive → semantic（组件只许引用这层）→ component。
  `scripts/check.mjs` §8 设计 lint 强制：**组件 CSS 裸 hex = 门禁失败**。
- 六色 `data-accent` 调色盘机制保留（色值已完成 AA 调校，全部继承）。
- 事件色 =「批改」隐喻：`--ok` 墨绿、`--bad` 朱砂。
- 双主题（浅/深）正文与关键色对比度 **≥ 4.5**，新增色值必须过对比度门禁。

### 1.3 动效

- 时长：`--dur-fast 150ms` / `--dur 240ms` / `--dur-slow 360ms`，进入用 `--spring`。
- **全部受 `prefers-reduced-motion` 约束**。
- 高光只给判分时刻：答对槽格墨绿涟漪（`ink-ripple`）、换词槽位落墨入场（`ink-in`）、辨析卡以「批注纸」形态弹入。
- 禁止视差 / 粒子装饰类动效。讲义词卡 → 详情走 **View Transitions 词头共享元素**。

### 1.4 图标

- emoji → **内联 SVG sprite**（`#i-*` 符号，两页同源，`currentColor` 着色）。结构性控件（导航 / 同步态 / 朗读 / 报错 / 标记 / 分页）全部图标化。
- ★ ☆ ✓ ✗ ✕ 保留为**文本字形**（无 VS16、可着色，lint 白名单放行）。
- 章节列表不用 emoji，改**编号瓷片**（`.ch-tile`，衬线数字）。

### 1.5 关键界面约定

- **刷词页**：词面 hero（`--fs-hero`）/ 墨格方格纸字母槽 / 答题卡（mono keycap + 抬升阴影）/ **底部拇指坞**（`提交` 主 CTA 居中，`生词·不会·上一个·重置本题` 侧翼，其余收进「⋯」快捷菜单）/ 顶栏每日目标 SVG 进度环。
- **操作坞控件 id 不变、事件绑定零改动**——改布局不改接线。
- **讲义页**：词卡衬线词头 + `content-visibility:auto` / ⌘K、Ctrl+K、`/` 命令面板 / 搜索框 SVG 放大镜。
- **存储**：配图 / 批注 / 画笔 dataURL 走 **IndexedDB**（`public/idb.js`），localStorage 只留备注与元数据。

## 2. 门禁（设计相关）

| 机制 | 位置 | 内容 |
| --- | --- | --- |
| 设计 lint | `scripts/check.mjs` §8（4 项） | ① 组件 CSS 禁裸 hex ② 两页 HTML + 公共 JS/CSS 禁 emoji ③ 全 CSS 禁 `outline:none` ④ 禁外部字体源 / `@import` |
| 对比度门禁 | `scripts/check.mjs` §6 | 六盘 ink ≥4.5 双主题；正文 `text-3` / `ok` ≥4.5 |
| 视觉回归 | `npm run ui:baseline` | Playwright 5 场景截图 → `shots/baseline/`（入库）/ `shots/current/`（忽略），配 pixelmatch 类工具比对 |
| 无障碍 | `npm run a11y` | axe-core 注入两页，critical/serious > 0 → exit 1（缺本地包时 exit 2，不阻塞） |

改视觉后的收口顺序：`npm run check` → `npm test` →（改了界面）`npm run smoke` → `npm run ui:baseline` → 部署后 `npm run verify:live`。

## 3. 明确不做（及理由）

- **不引框架重写**：低组件数、高状态密度的工具型页面，框架 ROI 为负。
- **不上中文 webfont**、**不做视差/粒子装饰**。
- **不做双皮肤并行**（`@layer classic/next` 在层叠上比 git 按期回滚更脆弱）→ 出问题按期 `git revert`。
- 设计改动**不碰存储协议与同步语义**（LWW / 队列是可靠性资产）。

## 4. 遗留项（已知未做，勿重复提议）

1. `app.js`（约 3900 行）**模块拆分未做**：无浏览器环境里做 3000 行级搬移是最高回归风险项，留给独立一期（需能跑 `npm run dev` + `smoke` 的环境）。
2. PWA 图标仍为 SVG 单图标，缺 192/512 PNG 与 maskable 位图（`purpose: any maskable` 已声明）。
3. 深色主题首屏白闪修复受 CSP `script-src 'self'` 约束需内联脚本豁免，维持现状（HTML 已带 `data-theme` 初值）。
4. 设置面板渐进披露未做（现有五分组已够清晰，低优先级）。
