## 2. 前端文件职责边界（避免改错地方）

| 文件 | 职责 | 不该放这里的 |
| --- | --- | --- |
| `core.js` | 纯逻辑、无 DOM：判分、掌握判定、错词复现、统计、每日目标、分模式台账 | 任何 DOM 操作 |
| `quiz.js` | 认词出题纯逻辑：干扰项挑选、辨析文案、可注入 rng | DOM、状态 |
| `app.js` | 刷词页 DOM 与状态机（含 `state` 全局状态对象） | 可复用的纯逻辑（应下沉 core.js） |
| `ui.js` | 跨页共用组件与主题 | 页面专属业务 |
| `idb.js` | IndexedDB KV（配图/批注/画笔） | 业务状态 |

**状态入口**：`app.js` 顶部的 `state` 对象（deck/index/answered/answerLog/questions…）。改答题流程前先看这个对象的字段定义。

## 4. 运行依赖与本地起法

- 静态资源可直接 `python -m http.server` 起在 `public/`（纯前端调试够用；API 会 404，走 guest/本地存档）。
- 完整链路：`npm run db:migrate:local` → `npm run dev`（127.0.0.1:8787）→ `npm run e2e` / `npm run smoke`。
- Playwright 未下载浏览器内核时，脚本按 `chrome` → `msedge` → 默认 顺序回退（`scripts/smoke.mjs` 的 `launch()`）。
