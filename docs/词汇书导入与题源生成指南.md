# 词汇书导入与题源生成指南

> 目标：**只输入一本词汇书**（xlsx / csv / tsv，包含"外语词 + 中文释义"，甚至只有外语词），
> 生成系统所需的全部资源：`data-N.json` 分章词库 + 认词题源（正向 `distractors` + 反向 `rev`）。
> 机器可判部分由校验器把关，语义质量按《选择题资料生成规范.md》验收。

---

## 管线总览

```
词汇书（xlsx/csv/tsv）
  │  ① node scripts/import-book.mjs <文件> --title "书名" --chapters N
  ▼
public/data-N.json 分章词库 + chapters.js 追加        ← npm run check 核对
  │  ②（仅当词汇书只有外语词）模型补中文释义
  │  ③ node scripts/quiz.mjs prompt <章> --limit 50 [--rev]
  ▼
提示词 → 贴给任意模型 → 返回 JSON 存 content/quiz/N-*.json
  │  ④ node scripts/quiz.mjs merge content/quiz/N-*.json --chapter N
  ▼
public/quiz-N.json（校验失败不写入）                  ← npm run quiz:check
  │  ⑤ node scripts/quiz.mjs sample --chapter N --count 8 [--rev] 人工抽查
  │  ⑥ node scripts/quiz-flag.mjs 逐题缺陷扫描
  ▼
npm run check && npm test && npm run smoke           ← 门禁
  │  ⑦ git push（自动部署）→ npm run verify:live
```

## ① 导入词汇书

```bash
node scripts/import-book.mjs "5500词汇.xlsx" --title "5500 核心词" --chapters 24 --start 23
```

- **列识别**：优先按表头（单词/word、解释/释义/meaning、音标/phonetic）；无表头时按内容猜
  （拉丁字母最多的列 = 单词，含中文最多的列 = 释义；音标列按 IPA 字符识别）。
- **分章**：`--chapters N` 按行均匀切；`--by-sheet` 每个工作表一章；默认整本一章。
- **sheet 选择**：多工作表常是同一本书的多轮副本，默认自动挑结构最完整的一张，`--sheet 名称` 可指定。
- **防覆盖**：目标 `data-N.json` 已存在时报错退出；`--start 23` 指定起始章号（默认排现有章节之后）。
- **只有外语词**：导入成功但词条无释义——用下面的补释义提示词让模型补全，再重新导入（或直接手改 JSON）。

### 补释义提示词（仅有外语词时）

```
你是雅思词汇编辑。下面是单词列表（每行一个）。为每个词给出一行中文释义，
格式与词库一致：`word<TAB>pos.中文释义1；中文释义2`。
要求：词性缩写在前（n./v./adj./adv.），义项用中文分号分隔，不要例句，只输出列表。
```

## ② 生成认词题源（正向 + 反向同一批）

```bash
# 正向提示词（看英文选中文）
node scripts/quiz.mjs prompt 23 --limit 50 --out prompt-23-1.md
# 反向提示词（看中文选英文；规范见《选择题资料生成规范.md》§11）
node scripts/quiz.mjs prompt 23 --limit 50 --rev --out prompt-23-rev.md
```

把提示词贴给任意模型（Gemini/GPT/Claude/DeepSeek 均可），返回的**纯 JSON** 存为
`content/quiz/23-1.json`（正反向可以合成一个文件：正向字段 + 每词的 `rev` 字段，spec 1.1）。

合并（先校验，有错不写入；一片 40~60 词，跑一次 check 再继续下一片）：

```bash
node scripts/quiz.mjs merge content/quiz/23-1.json --chapter 23
```

**红线速记**（详见规范）：恰好 3 个干扰项；kind 配额 topic≤2/pos≤1/antonym≤1 且至少 1 个
root/form/sense/antonym；why ≤40 字点名区分点；**禁止任何脚本事后只替换 text**；
反向题源禁用 sense/pos，干扰词不得与答案互为屈折、词义与题面互含即废。

## ③ 校验与验收

```bash
npm run quiz:check                                   # 全库校验（error 必须为 0）
node scripts/quiz.mjs sample --chapter 23 --count 8 --rev   # 人工抽查（正反向各来一轮）
node scripts/quiz-flag.mjs                           # 逐题缺陷扫描 → _audit/work/
```

规范 §9 验收标准：覆盖率 ≥80%、抽样 ≥7/8 值得混淆、歧义 ≤1/20；
`quiz:check` 的 error、`quiz-flag` 的 err/ambig/misalign/tmpl/dupwhy 必须为 0。

## ④ 门禁与上线

```bash
npm run check && npm test
npm run smoke        # 需本地 dev 服务
git push             # 自动部署 vocab.logicc.top（约 1 分钟）
npm run verify:live
```

## ⑤ agent/SKILL 用法

`.zcode/skills/book-to-vocab/SKILL.md` 把本指南封装成了可被 agent 直接执行的技能：
给它词汇书路径即可，它会按 ①→④ 全程执行并在每道门禁停下核对。
