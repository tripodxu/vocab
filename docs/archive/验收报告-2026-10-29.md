## 4. 发现的问题（按优先级）

### F1 · P3 · 注册不继承访客个性化（走查 E3，3 次复现）

- **现象**：访客把主题色改为 emerald → UI 注册新账号 → 刷新后色盘回到默认 sky。
- **根因**：本地存档按 `vocab:v3:<userKey>.*` 命名空间隔离；注册切换 userKey 后读新命名空间（空 → 默认值），
  而新账号云端 `GET /api/vocab/settings` 返回 `{ settings: null }`（`worker/index.js handleSettingsGet`），
  `syncPull` 的合并分支因 settings 为 null 跳过，没有任何「本机 → 云端」的种子迁移。
- **影响**：用户注册前的所有本机偏好（色盘、目标、音效等）在注册后归零，须重新配置；学习进度本身有
  `applyUser` 前的落盘与合并路径，不受影响（smoke 已覆盖进度场景）。
- **建议**：注册成功且首次 `syncPull` 发现云端无 settings 时，把本机 `state.settings` 作为初始值 `PUT` 上云
  （顺带解决多设备首登体验）；或在注册弹层加一句预期说明。

### F2 · P3 · 讲义「词头飞入」过渡从未生效 + console 报错（走查 G 阶段，桌面/移动均复现）

- **现象**：讲义页 console 出现 `Unexpected duplicate view-transition-name: word-hero`（桌面与移动端各一次）。
- **根因**：`lecture.js openDetail()` 把列表词头 `.w` 设为 `viewTransitionName="word-hero"`（L672），
  详情标题也设同名（L732，弹层存在期间不清除）；而 `cleanup()`（清词头名）挂在过渡**结束后**——
  过渡的**新快照树**里词头与标题同名，浏览器按规范放弃整个过渡并报错。表现 = 详情照常打开，但飞入动画从未真正播放，
  且每次打开详情都留一条 console error。
- **建议**：把词头名的清理挪进 `startViewTransition` 的更新回调内（旧快照已捕获，不受影响），
  或详情标题仅在过渡期间临时命名。顺带回归验证一次动画真实生效（录屏对比）。

### F3 · P3 · 「连续天数」口径易误读（走查观察）

- 报告页「连续天数 0」与「今日进度 5/50」并存。口径实为**连续达成每日目标的天数**
  （`core.js recordDaily`：仅 `achievedNow` 时 streak +1），设计正确，但字面易被理解为「连续学习天数」。
- **建议**：文案改「连续达标」或在卡片加副标「达成 50 词/天计 1 天」。

### F4 · P3 · ⌘K 搜索仅限当前章，未说明（走查 G4）

- palette 词条搜索遍历 `state.words`（当前章），placeholder 写「搜索单词 / 释义」；
  「tax」在第 2 章、当前第 1 章时结果 0 条（本次走查即误判过一次）。
- **建议**：升级为跨章全局搜索（结果带「第 N 章」标注，点击跳章），成本不高（CHAPTERS 已全量在前端）；
  短期至少把 placeholder 改为「在当前章内搜索…」。
