## 1. 关键设计

### 1.1 掌握与易错权重（core.js 纯函数，可单测）

```
applyResult(prev, correct, now, { streakStep = 1 } = {})
  认词模式调用传 streakStep: 2 → 答对一次 cs=2 即 mastered（"认识即掌握"落地）

weight = 1.0（首次答错初始化）
答错：weight = min(3.0, weight * 1.5 + 0.5)
答对：weight = max(0.1, weight * 0.7)     → 永远 > 0，除非手动删除
复现次数 = clamp(round(weight), 1, 3)     → 每轮牌堆中该词额外出现次数
```

- 权重与"曾错标记"存本机（`state.weights`，随存档持久化，不进云端协议——与分模式台账同级的取舍）；
- 错题本抽屉改为"**易错词**"：数据源 = 曾错集合（与 word.s 无关），按权重降序，含手动删除；
- 复习会话的"错题"同样取易错集合；
- "本章已掌握"统计口径不变（认词修复后数字会正常增长）。

### 1.2 举报数据模型

```sql
CREATE TABLE question_report (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id INTEGER NOT NULL,
  chapter INTEGER NOT NULL,
  word_id INTEGER NOT NULL,
  kind TEXT NOT NULL,          -- similar/options-wrong/meaning-wrong/other
  note TEXT,
  created_at TEXT NOT NULL DEFAULT (datetime('now'))
);
```

导出：`GET /api/quiz/report/export?token=<ADMIN_TOKEN>`（env 配置，未配置=404），CSV 输出。
