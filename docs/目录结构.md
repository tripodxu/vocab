# 目录结构（一张表看懂仓库怎么摆的）

> 给谁看：新接手的人与 agent。**看完这张表就不用逐个目录翻了**。
> 原则：运行时代码、工具链、证据/审计、本地产物**四层分离**；依赖方向单向，不允许反向。

---

## 1. 分层总览

| 层 | 目录 | 是否入库 | 能否改 | 说明 |
| --- | --- | --- | --- | --- |
| **运行时** | `public/`、`worker/`、`migrations/` | ✅ | 正常改 | 线上真正跑的东西 |
| **工具链** | `scripts/` | ✅ | 正常改 | 校验 / 检查 / 题源 CLI / 门禁 |
| **测试** | `test/` | ✅ | 正常改 | `node --test`，210 项 |
| **文档** | `docs/`、根目录 `README.md` `AGENTS.md` `MEMORY.md` | ✅ | 改代码就要改文档 | 索引见 `docs/README.md` |
| **内容/中间产物** | `content/quiz/`、`public/data-N.json`、`public/quiz-N.json` | ✅ | 走工具链改 | 词库是唯一数据源；题源走 `quiz.mjs` 收口 |
| **证据（一次性）** | `_archive/` | ✅ | **禁止运行**，只读 | 一次性脚本与快照，见 `_archive/README.md` |
| **审计/复核** | `_audit/` | 部分（脚本入、报告不入） | 只读 | 独立复核工具，见 §3 |
| **本地产物** | `_backup/`、`shots/current/`、`.wrangler/`、`node_modules/` | ❌ gitignore | 随意 | 不入库，勿依赖 |

## 2. 逐个目录

| 路径 | 用途 | 被谁依赖 / 注意 |
| --- | --- | --- |
| `public/` | 前端静态页（无框架原生 JS）+ 词库 + 题源 + PWA | `worker/index.js` 提供静态资源；**源码**在这里，`app.js`（~3800 行）与 `lecture.js`（~2040 行）是最大的两个 |
| `public/dist/` | **构建产物**（esbuild 压缩 + 指纹）：`app.<hash>.js`、`tokens.<hash>.css`、共享 `chunk.<hash>.js`、`manifest.json` | `npm run build:assets` 生成；HTML 引用由它改写；`.gitignore` 已忽略，**不要手改** |
| `worker/` | Cloudflare Worker 唯一入口：鉴权 / 学习状态 / 备注配图 / admin API | `wrangler.jsonc` |
| `migrations/` | D1 表结构 `0001~0009`；**已应用的不可改** | 部署前 `npm run db:migrate` |
| `scripts/` | 工具链：校验（quiz-lib / quiz-data / check）、题源 CLI（quiz.mjs 及 quiz-*）、门禁（smoke / e2e / verify-live / a11y / ui-baseline） | `package.json` scripts；`npm run check` 会校验模块接线 |
| `test/` | 单元测试 + `fake-d1.js`（Worker 测试替身） | `npm test` |
| `docs/` | 规范 / 指南 / agent 协作 / 归档（见 `docs/README.md`） | `docs/选择题资料生成规范.md` 被 `check.mjs` 硬引用，**不可改名** |
| `content/quiz/` | 模型产出的题源分片（合并前的中间产物，**保留作溯源**） | `quiz.mjs merge`、`quiz-rebuild.mjs`；**不是运行时数据源** |
| `_archive/` | 一次性脚本与证据，分 `length-fix/` 与 `quiz-fix/` 两组 | **禁止运行** |
| `_audit/` | 独立复核脚本（`indep/` 下 s1~s9 等）+ 报告产物（`work/`、`*.json` 不入库） | 见 §3 |
| `_backup/` | 本地备份快照（未入库） | 勿改，勿依赖 |
| `shots/` | 截图：`baseline/`（入库，视觉回归基线）/ 根目录与 `current/`（不入库） | `npm run ui:baseline` |
| `.workbuddy/` | IDE 会话记忆与日志（项目记忆的同步副本） | 记忆正文以根目录 `MEMORY.md` 为准 |

根目录其余文件：`wrangler.jsonc`（Worker 配置）、`package.json`、`tsconfig.json`（仅类型提示，不上编译）、
`serve.bat`（给人双击用的**静态预览**入口，无 API；完整链路用 `npm run dev`）、`.dev.vars`（本地密钥，已 gitignore）。

## 3. 依赖方向（**单向，禁止反向**）

```
scripts/quiz-lib.mjs   ← 纯逻辑：规范常量 + 校验器（不读文件，可单测）
scripts/quiz-data.mjs  ← 数据层：读词库/题源、建索引、相似度、why 解析
        ↑                        ↑
   scripts/quiz*.mjs（题源 CLI 与修复工具）
        ↑
   _audit/**（审计/复核脚本，允许依赖 scripts）
```

**禁止**：生产脚本（`scripts/`、`test/`、`public/`）import `_audit/` 或 `_archive/` 下的任何文件——
那里是一次性审计脚本，标注"禁止运行"。历史上 `quiz-flag/optimize/rev-generate` 曾反向 import `_audit/indep/lib.mjs`，
已于 2026-09-28 把共用函数上移到 `scripts/quiz-data.mjs` 修正。

`_audit/indep/lib.mjs` 现在只做转发 + 保留审计专用输出函数，审计脚本（s1~s9 等）继续可用。

**前端模块（2026-09-30 拆分后）**：

```
core.js ──► state.js ──► storage.js ──┐
                     └──► speech.js ──┼──► app.js
core.js ──► lecture-store.js ─────────┼──► lecture.js
```

`state.js` 必须先于 `storage.js` / `speech.js` 存在：state 若留在 `app.js`，后两者就得反向 import app.js 而**成环**。
新模块**禁止** import `app.js` / `lecture.js`（`npm run check` 第 1 节会把它们逐个 import 一遍，成环会直接报错）。
